## Architecture Decisions
- **DOM bypass pattern**: 3D dial/works wheel transforms mutate `element.style` directly (no React state) for 120 FPS drag performance.
- **Portal isolation**: Freebies detail overlay rendered via `createPortal(document.body)` to escape parent `will-change:transform` stacking contexts.
- **Eager AudioContext**: Single `AudioContext` created on mount, resumed on first gesture — avoids browser autoplay policy issues.
- **Shared lib/hooks**: Extracted duplication into `src/lib/` and `src/hooks/` — navigation constants, screen size, font loading, utility functions.
- **Lenis over GSAP**: Global smooth scroll via Lenis (not GSAP ScrollTrigger) for homepage 3D Z-axis camera flythrough.
